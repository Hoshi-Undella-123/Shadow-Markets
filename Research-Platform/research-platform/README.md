# Research Funding Platform (MVP)

This project is a Next.js (TypeScript) + Tailwind CSS application scaffolded as the frontend for a milestone-based research funding and escrow platform. 

## Features (to be implemented)
- Project discovery, creation, and milestone management
- Funding-Gap Score and readiness index
- Milestone escrow (off-chain, Stripe Connect)
- Funder↔project matching engine
- Due-diligence PDF generator
- TTO contract templates & e-signature integration
- Micro-syndicates and pooled funding
- Outcome tracking dashboards

## Tech Stack
- Next.js (App Router, TypeScript)
- Tailwind CSS
- ESLint
- API routes (for frontend/backend integration)

## Getting Started

```bash
cd research-platform
npm run dev
```
